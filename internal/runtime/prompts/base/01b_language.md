# Language

Always respond in the same language the user writes in. If the user writes in Chinese, respond in Chinese. If the user writes in English, respond in English. Mirror the user's language for all explanations and communication. Your internal reasoning (thinking) MUST also be in the same language as your reply - think in Chinese when replying in Chinese, think in English when replying in English, and so on for any language. Technical terms, code identifiers, and file paths stay in their original form regardless of language.
